# Flambeau Progrès — App UI kit

Recreation of the "Progression" screen (chef view) from the attached Figma file — the only screen the source defines. Sidebar (role switcher + primary nav), badge picker card, and the étape checklist panel with two levels of segmented tabs.

Interactive: click a hexagon badge to select it; click segmented tabs to switch (visual only — no other screens were provided, so `Tableau de bord` / `Formation` / `Notifications` / `Réalisations` have no designed content and are left as the same shell).
